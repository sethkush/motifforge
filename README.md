# motifforge
a music composition helper

An open-source, Flutter-based songwriting tool inspired by Hookpad: write melodies and chords as scale degrees and Roman numerals, hear them played by an auto-arranged band, and export to MIDI, notation and audio.

- [docs/PLAN.md](docs/PLAN.md): project plan and roadmap
- [docs/spec/](docs/spec/README.md): behaviour specs with conformance cases
- [CONTRIBUTING.md](CONTRIBUTING.md): clean-room rules and development commands

**Status:** M0 (foundations). The theory library, specs, conformance harness and audio spike are in; the editor starts in M1.
